# Build prompt

Create an original Android anti-stress toy collection inspired by the general category of tactile relaxation apps, without copying proprietary source code, artwork, sounds, branding, layouts, or other protected assets from JindoBlu Antistress.

Requirements:
- Kotlin Android app, portrait-first, offline and no account required.
- Calm tactile visual language: warm neutral background, rounded cards, restrained pastel palette, minimal text.
- Home grid opens independent touch toys.
- Implement interactions from scratch with Android Canvas/custom views.
- Include bubbles, pressable buttons, water-like ripples, inertial spinner, free drawing, switches; expand later with original mechanics.
- Add subtle haptic feedback where appropriate.
- No ads, analytics, trackers, network permission, or external game assets in the test build.
- Keep mechanics responsive at 60fps where possible.
- Build a debug APK in GitHub Actions and publish it as a workflow artifact.
- Use the original app only as high-level product inspiration; do not reproduce its source, assets, trademarks, or exact screen designs.
